# 高级分块策略对比评估报告

> 生成时间：2026-08-21 18:15:12

> 检索方式：Hybrid (BM25+Vector+RRF)
> 命中判断：bigram 覆盖率 ≥ 0.2（chunk 的 bigram 覆盖 golden_answer 的比例）

## 一、分块策略说明

| 策略 | 原理 | 优势 |
|------|------|------|
| 固定500字/100重叠（基线） | 递归分隔符切分，系统当前默认 | 实现简单，均衡 |
| 父子分块(Small-to-Big) | 子块300字检索，命中后返回父块800字 | 精确匹配+完整上下文 |
| 语义分块(Semantic) | 用 embedding 计算句子相似度，语义断点切分 | 语义完整性 |
| 递归结构化分块 | 按「第X章/节/条」标题层级切分 | 法规结构保持 |
| 滑动窗口(50%重叠) | 500字块，250字重叠 | 高召回，防边界断裂 |

## 四、结论与建议

1. 检索召回最优分块策略为 **语义分块(Semantic)**（Recall@5=86.50%）。
2. 父子分块在精确匹配的同时保留完整上下文，适合跨块综合问答。
3. 语义分块保证语义完整性，但需要 embedding 模型支持，增加计算开销。
4. 结构化分块保持法规层级，对条文类文本效果好。
5. 滑动窗口通过高重叠率防止答案被切断，但分块数翻倍。
6. 语义父子分块（先语义切父块+子块300字检索）Recall@5=84.50%、CP@5=53.50%，介于纯语义(86.5%)与纯父子(84.0%)之间，单一指标未超越两者最优；其价值在父块语义完整的上下文质量，不在检索命中指标。
