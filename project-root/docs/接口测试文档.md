## 1. 认证

### 1.1 登录

- 方法/路径：`POST /auth/login`
- 鉴权：无

请求体：

```json
{"username":"zhangsan","password":"Abc@123456"}
```

成功响应 `data`：

```json
{
  "access_token": "eyJ...",
  "refresh_token": "eyJ...",
  "expires_in": 7200,
  "user": {
    "id": "U002",
    "username": "zhangsan",
    "name": "张三",
    "role": "SafetyOfficer",
    "department": "安全生产部",
    "project": "成绵高速扩容项目"
  }
}
```

错误码：`40101` 用户名或密码错误、`40102` 账户已禁用、`40001` 参数校验失败。

curl 示例：

```powershell
curl.exe -X POST "http://127.0.0.1:8000/api/v1/auth/login" -H "Content-Type: application/json" -d "{\"username\":\"zhangsan\",\"password\":\"Abc@123456\"}"
```

### 1.2 获取当前用户

- 方法/路径：`GET /auth/me`
- 鉴权：Bearer

```powershell
curl.exe "http://127.0.0.1:8000/api/v1/auth/me" -H "Authorization: Bearer $TOKEN"
```

### 1.3 退出登录

- 方法/路径：`POST /auth/logout`
- 鉴权：Bearer

```powershell
curl.exe -X POST "http://127.0.0.1:8000/api/v1/auth/logout" -H "Authorization: Bearer $TOKEN"
```

成功：`{"code":0,"message":"已退出登录"}`。

### 1.4 刷新 Token

- 方法/路径：`POST /auth/refresh`
- 鉴权：无

请求体：

```json
{"refresh_token":"eyJ..."}
```

成功响应同登录接口：返回新的 `access_token`、`refresh_token`、`expires_in` 和 `user`。

错误码：`40103` refresh_token 无效或已过期。

```powershell
curl.exe -X POST "http://127.0.0.1:8000/api/v1/auth/refresh" -H "Content-Type: application/json" -d "{\"refresh_token\":\"$REFRESH_TOKEN\"}"
```

### 1.5 修改密码

- 方法/路径：`PUT /auth/password`
- 鉴权：Bearer

请求体：

```json
{"old_password":"Abc@123456","new_password":"Xyz@654321"}
```

错误码：`40104` 旧密码错误、`40001` 新密码复杂度不足。

## 3. 隐患管理

### 3.1 隐患上报（H01）

- 方法/路径：`POST /hazards`
- 鉴权：Admin / SafetyOfficer / Employee
- 请求：`multipart/form-data`

| 参数 | 类型 | 必填 | 说明 |
|---|---|---|---|
| title | string | 是 | ≤100 字 |
| description | string | 是 | ≤2000 字 |
| level | string | 是 | critical / major / minor / trivial |
| category | string | 是 | 如 edge_protection / fire_safety / machinery |
| location | string | 是 | 位置描述 |
| location_coords | string | 否 | `lng,lat` |
| occurred_at | string | 是 | ISO 8601 |
| project | string | 是 | 所属项目 |
| images | file[] | 否 | 最多 9 张 |
| detections_json | string | 否 | AI 识别结果 JSON 数组，格式见下；用于把 AI 检测结果和标注图一起保存进隐患 |

`detections_json` 可选，格式示例（`image_index` 对应 `images` 的上传顺序）：

```json
[
  {
    "image_index": 0,
    "detections": [
      {
        "id": 1,
        "label": "临边防护缺失",
        "risk": "high",
        "bbox_norm": [0.2, 0.2, 0.6, 0.6],
        "bbox_px": [20, 20, 60, 60],
        "color_bgr": [0, 0, 255],
        "conf": 0.9,
        "fix": "立即设置临时防护",
        "note": "桥墩东侧"
      }
    ]
  }
]
```

> 说明：不传 `detections_json` 就是「纯上报信息 + 照片」；传了就是把 AI 检测结果和标注图一并存进隐患，`H03 详情` 的 `media.detections` 和 `media.annotated_images` 中可查看。

成功响应 `data`：

```json
{"hazard_id":"HD-20260814-0001","status":"pending","created_at":"..."}
```

curl 示例（无图片）：

```powershell
curl.exe -X POST "http://127.0.0.1:8000/api/v1/hazards" `
  -H "Authorization: Bearer $TOKEN" `
  -F "title=3号桥墩临边防护缺失" `
  -F "description=桥墩施工区域临边护栏缺失约5米" `
  -F "level=major" `
  -F "category=edge_protection" `
  -F "location=K12+350" `
  -F "occurred_at=2026-08-12T09:30:00+08:00" `
  -F "project=成绵高速扩容项目"
```

带图片：

```powershell
curl.exe -X POST "http://127.0.0.1:8000/api/v1/hazards" `
  -H "Authorization: Bearer $TOKEN" `
  -F "title=现场隐患" -F "description=现场发现的安全隐患描述" `
  -F "level=major" -F "category=edge_protection" -F "location=现场" `
  -F "occurred_at=2026-08-12T09:30:00+08:00" -F "project=成绵高速扩容项目" `
  -F "images=@C:\path\to\photo.jpg"
```

### 3.7 隐患验收（H06）

- 方法/路径：`POST /hazards/{hazard_id}/review`
- 鉴权：Admin / SafetyOfficer；Employee 返回 `40303`


或驳回（comment 必填且 ≥10 字）：

错误码：`40010` 状态不允许验收、`40011` 驳回未填写原因（<10 字）、`40301`、`40303`。

```powershell

  -H "Authorization: Bearer $TOKEN" -H "Content-Type: application/json" `
```

## 6. AI 智能助手

### 6.1 AI 问答（SSE 流式，A01/A03/A05/A06）

- 方法/路径：`POST /ai/chat`
- 鉴权：Admin / SafetyOfficer / Employee
- 请求头：`Accept: text/event-stream`、`Content-Type: application/json`

请求体：

```json
{"session_id":"sess_可选","question":"高处作业安全带的使用标准是什么？"}
```

首次提问不传 `session_id`，服务端会在 `done` 事件中返回新的 `session_id` 和 `message_id`。

SSE 事件：`token`（逐段回答）、`sources`（引用来源）、`done`（完成）、`error`（错误）。

错误码（`error` 事件）：`40201` 敏感词拦截、`40203` AI 服务不可用、`42901` 频率超限。

```powershell
curl.exe -N -X POST "http://127.0.0.1:8000/api/v1/ai/chat" `
  -H "Authorization: Bearer $TOKEN" -H "Accept: text/event-stream" -H "Content-Type: application/json" `
  -d "{\"question\":\"高处作业安全带的使用标准是什么？\"}"
```

```json
}
```

`threshold` 不传时使用 `RAG_RERANK_THRESHOLD=0.3`。低于阈值的候选会被过滤；没有候选时 `no_evidence` 为 `true`。

## 7. 端到端测试流程（完整闭环）

建议按顺序执行（PowerShell）：

1. 登录安全员 zhangsan，记下 token：

```powershell
$resp = curl.exe -X POST "http://127.0.0.1:8000/api/v1/auth/login" -H "Content-Type: application/json" -d "{\"username\":\"zhangsan\",\"password\":\"Abc@123456\"}"
$TOKEN = ($resp | ConvertFrom-Json).data.access_token
```

2. 上报隐患（得到 `hazard_id`）：

```powershell
curl.exe -X POST "http://127.0.0.1:8000/api/v1/hazards" -H "Authorization: Bearer $TOKEN" -F "title=临边防护缺失" -F "description=桥墩施工区域临边护栏缺失约5米" -F "level=major" -F "category=edge_protection" -F "location=K12+350" -F "occurred_at=2026-08-12T09:30:00+08:00" -F "project=成绵高速扩容项目"
```

3. 派单给 lisi（`assignee_id=U003`），状态应变为 `processing`：

```powershell
curl.exe -X POST "http://127.0.0.1:8000/api/v1/hazards/{hazard_id}/assign" -H "Authorization: Bearer $TOKEN" -H "Content-Type: application/json" -d "{\"assignee_id\":\"U003\",\"requirements\":\"立即设置临时防护并安装正式护栏\",\"deadline\":\"2026-08-20T18:00:00+08:00\",\"priority\":\"high\"}"
```

4. 登录 lisi，提交整改（带整改后照片），状态应变为 `pending_review`：

```powershell
curl.exe -X POST "http://127.0.0.1:8000/api/v1/hazards/{hazard_id}/rectify" -H "Authorization: Bearer $LISI_TOKEN" -F "measures=已设置临时防护并安装正式护栏，经复查验收合格完成整改" -F "images_after=@C:\path\to\after.jpg"
```

5. 用 zhangsan 验收通过，状态应变为 `closed`：

```powershell
curl.exe -X POST "http://127.0.0.1:8000/api/v1/hazards/{hazard_id}/review" -H "Authorization: Bearer $TOKEN" -H "Content-Type: application/json" -d "{\"result\":\"approved\"}"
```

6. 查看 lisi 的通知（应收到派单、验收结果通知）：

```powershell
curl.exe "http://127.0.0.1:8000/api/v1/notifications?read_status=all" -H "Authorization: Bearer $LISI_TOKEN"
```

7. 用 admin 查看统计看板：

```powershell
curl.exe "http://127.0.0.1:8000/api/v1/statistics/hazards/overview" -H "Authorization: Bearer $ADMIN_TOKEN"
```
