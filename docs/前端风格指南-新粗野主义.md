# 前端风格指南 — Neo-Brutalism（新粗野主义）

> 版本：v1.0 ｜ 适用：蜀道安全助手前端（Vue 3 + TypeScript + Element Plus）
> 风格基调：粗黑边框、硬阴影、无圆角、高对比、强交互反馈

---

## 一、风格概述

本风格源自 Neo-Brutalism（新粗野主义）设计语言，核心特征是**"硬"与"直"**：

- 拒绝柔和渐变、圆角、弥散阴影，改用**粗描边 + 硬偏移阴影**制造体积感
- 高对比配色（黑 / 白 / 高饱和强调色），信息层级靠边框与色块而非透明度
- 交互反馈直接、夸张（位移、反色、覆盖层），让用户"看得见"每一次操作

适用场景：管理后台、工具型页面、数据看板等需要强辨识度与操作感的界面。

---

## 二、设计原则

| 原则 | 说明 |
|---|---|
| 粗边框优先 | 所有可交互元素使用 ≥3px 实色描边，替代阴影/渐变做边界 |
| 硬阴影 | 阴影无模糊（`box-shadow: Xpx Ypx 0 #000`），模拟"印刷错位" |
| 无圆角 | 默认 `border-radius: 0`，保持硬朗轮廓 |
| 高对比 | 主色黑、底色白、强调色高饱和，正文不透明度不低于 90% |
| 反馈可见 | hover / focus / active 必须有明显状态变化（位移、反色、覆盖层） |

## 三、色彩规范

| Token | 色值 | 用途 |
|---|---|---|
| `--color-ink` | `#000000` | 主文字、描边、主按钮底色 |
| `--color-paper` | `#FFFFFF` | 页面/卡片背景 |
| `--color-accent` | `#5AD641` | 强调色（确认、成功、覆盖层） |
| `--color-warn` | `#FFB800` | 警告、待处理 |
| `--color-danger` | `#FF4D4F` | 错误、删除 |
| `--color-info` | `#1677FF` | 信息、链接 |

> 规则：强调色仅用于"动作结果"（如按钮 hover 覆盖层、成功提示），不作为大面积背景。

## 六、组件规范

### 1. 卡片（Card）

- 容器：`border: 6px solid #000` + `box-shadow: 12px 12px 0 #000`
- hover：`translate(-5px, -5px)` + 阴影加深至 `17px 17px 0`
- 标题：底部 3px 下划线，hover 时从左滑入（`translateX(-100% → 0)`）

### 2. 按钮（Button）

- 默认：黑底白字、3px 黑描边、`text-transform: uppercase`
- hover：绿色覆盖层（`::before` 内容如 "Sure?"）从下方滑入
- active：`scale(0.95)` 按下反馈
- 宽度建议 50%，居中偏左，避免全宽按钮

### 3. 输入框（Input）

- 默认：白底、3px 黑描边
- focus：`scale(1.05)` 放大 + 反色（黑底白字），`outline: none`
- 宽度：`calc(100% - 26px)` 补偿 padding 与边框

### 4. 表单（Form）

- 纵向排列，`gap: 15px`
- 输入框与按钮同宽对齐，保持视觉节奏

---

## 七、交互与动效规范

| 状态 | 动效 | 时长 |
|---|---|---|
| hover | 位移 / 覆盖层滑入 / 下划线滑入 | 0.3s |
| focus | 放大 + 反色 | 0.3s |
| active | 缩放 0.95 | 即时 |
| 抖动（预留） | `glitch` 关键帧（±2px 抖动，0.3s 循环） | 0.3s infinite |

> 动效统一使用 `transition: transform 0.3s, box-shadow 0.3s`，保持节奏一致。

## 九、使用注意事项

1. **克制使用强调色**：绿色覆盖层等效果仅用于关键操作，避免全页面滥用导致视觉疲劳。
2. **动效时长统一**：全部 0.3s，不单独调快调慢，保持节奏一致。
3. **可访问性**：反色（黑底白字）与高对比色块需保证对比度 ≥ 4.5:1；focus 状态必须可见。
4. **响应式**：卡片固定宽度场景（如 300px）在移动端需改为 `width: 100%` + 自适应阴影。
5. **与 Element Plus 共存**：本风格组件建议封装为独立组件库，覆盖 Element Plus 默认样式时使用 `:deep()` 或全局 CSS 变量覆盖。
