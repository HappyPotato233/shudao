# 前端风格指南 — 服务卡片（扩散填充风格）

> 版本：v1.0 ｜ 适用：蜀道安全助手前端（Vue 3 + TypeScript + Element Plus）
> 风格基调：亮白背景、圆形角标、hover 扩散填充、色彩语义化（绿=正向 / 红=消极）

---

## 一、风格概述

本风格源自"服务卡片 + 扩散填充"交互范式，核心特征是**"hover 时色彩从角标扩散覆盖全卡"**：

- 亮白色页面背景，卡片浅灰（`#f5f5f5`）浮于其上，干净清爽
- 右上角圆形角标承载序号，hover 时圆形从 50px 扩散至 900px 铺满整卡
- 扩散后文字反白，形成强烈的"聚焦/选中"反馈
- **色彩语义化**：正向内容用绿色，消极/毁灭性操作用红色，一眼可辨

适用场景：服务能力展示、功能入口卡片、操作确认卡片、危险操作按钮。

---

## 二、设计原则

| 原则 | 说明 |
|---|---|
| 亮白底 | 页面背景统一亮白（`#FFFFFF`），卡片浅灰（`#f5f5f5`）形成层级 |
| 色彩语义化 | 绿色=正向/安全/成功，红色=消极/毁灭/危险，语义不可混用 |
| 扩散反馈 | hover 时角标圆形扩散铺满卡片，文字反白，反馈强烈且直观 |
| 角标叙事 | 右上角圆形角标承载序号/编号，兼具装饰与信息 |
| 圆角克制 | 卡片 10px 圆角，柔和但不失结构感 |

## 六、组件规范

### 1. 服务卡片（Service Card）

- 结构：角标（`.number`）+ 图标（`.icon`）+ 标题（`.heading`）+ 描述（`.content`）
- 默认：浅灰底、10px 圆角、`box-shadow: 0 0 10px #4445` 轻投影
- hover：`scale(1.02)` + 阴影加深 + 角标圆形扩散铺满 + 文字反白

### 2. 正向卡片 / 按钮（Positive）

- 主色：`#22C55E`（绿）
- 适用：确认、通过、成功、安全、新增、开始
- hover：加深至 `#16A34A`，可复用扩散填充效果

### 3. 消极 / 毁灭卡片 / 按钮（Negative）

- 主色：`#EF4444`（红）
- 适用：删除、终止、清除、危险、失败、退出
- hover：加深至 `#DC2626`，可复用扩散填充效果
- 建议：毁灭性操作（如删除数据）需二次确认，红色作为视觉警示

### 4. 角标（Number Badge）

- 绝对定位右上角，圆形，承载序号
- 扩散动画由 `::after` 伪元素实现（初始 50px → hover 900px）

## 七、交互与动效规范

| 状态 | 动效 | 时长 |
|---|---|---|
| 卡片 hover | `scale(1.02)` + 阴影加深 | 0.4s ease-in-out |
| 角标扩散 | `::after` 从 50px 扩至 900px | 0.5s |
| 文字反白 | icon/heading/content 变 `#F5F5F5` | 0.5s |
| 按钮按下 | `scale(0.97)` | 即时 |

> 动效统一 `transition: all 0.4s ease-in-out`，扩散动画 0.5s 略慢于位移，形成层次。

## 九、使用注意事项

1. **色彩语义不可混用**：绿色只表正向、红色只表消极，禁止反向或混用，避免误导用户。
2. **毁灭性操作需二次确认**：红色按钮（删除/清除/终止）必须搭配确认弹窗，红色仅作视觉警示。
3. **扩散动画性能**：900px 圆形扩散在低端设备可能卡顿，可改用 `transform: scale()` 提升性能。
4. **可访问性**：反白文字与填充色对比度需 ≥ 4.5:1；红绿色盲用户需辅以图标/文字标识。
5. **响应式**：固定宽度（280px）在移动端需改为自适应；角标扩散尺寸按容器比例缩放。
6. **与 Element Plus 共存**：覆盖 Element Plus 按钮/卡片默认样式时使用 `:deep()` 或 CSS 变量。
