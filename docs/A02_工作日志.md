## 2. 隐患管理模块数据库构建

### 2.1 DDL 脚本（database/schema.sql）

完整建表脚本，覆盖 DATABASE.md 3.1-3.9 + 3.21-3.22 定义的 11 张表：

| 序号 | 表名                      | 说明                 | 索引数 | CHECK 约束 |
| ---- | ------------------------- | -------------------- | ------ | ---------- |
| 1    | roles                     | 角色表（RBAC 三级）  | -      | -          |
| 2    | users                     | 用户表               | 3      | is_active  |
| 3    | hazards                   | 隐患主表             | 5      | -          |
| 4    | hazard_media              | 隐患媒体附件         | 1      | -          |
| 5    | hazard_detections         | AI 隐患识别结果      | 2      | -          |
| 6    | hazard_assignments        | 隐患派单记录         | 2      | -          |
| 7    | hazard_rectifications     | 整改反馈记录         | 1      | -          |
| 8    | hazard_reviews            | 验收记录             | 1      | -          |
| 9    | hazard_timeline           | 隐患状态流转时间线   | 1      | -          |
| 10   | notifications             | 消息通知             | 2      | is_read    |
| 11   | notification_preferences  | 通知偏好             | -      | 6 个布尔   |

设计要点：
- `PRAGMA foreign_keys = ON` 启用外键约束
- 所有时间戳字段使用 `strftime('%Y-%m-%dT%H:%M:%S+08:00', 'now')` 动态默认值
- JSON 字段（attachments_json / images_json）添加 `DEFAULT '[]'`
- `ON DELETE CASCADE` 级联删除：hazard_media / hazard_detections / hazard_timeline / notifications 等子表
- `hazard_media.parent_media_id` 自引用外键：标注图关联原图，原图删除时级联删除标注图
- `hazard_detections` 表（DATABASE.md 3.5）：存储大模型视觉识别结果，含 `bbox_norm`/`bbox_px`/`color_bgr`/`conf` 等字段，对应 PRD H09
- 布尔值用 `INTEGER` + `CHECK(x IN (0,1))` 约束

### 2.3 SQLAlchemy ORM 模型（app/models/）

11 个 ORM 模型类，使用 SQLAlchemy 2.0 声明式风格（`Mapped` + `mapped_column`）：

| 文件           | ORM 类                                                            |
| -------------- | ----------------------------------------------------------------- |
| base.py        | Base（DeclarativeBase）、engine、SessionLocal、get_db()           |
| role.py        | Role                                                              |
| user_orm.py    | User                                                              |
| hazard.py      | Hazard、HazardMedia、HazardDetection、HazardAssignment、HazardRectification、HazardReview、HazardTimeline |
| notification.py| Notification、NotificationPreference                              |
| __init__.py    | 统一导出所有模型类                                                |

关键设计：
- engine 自动启用 `PRAGMA foreign_keys=ON`（`@event.listens_for`）
- 所有时间戳 `server_default=text("strftime('%Y-%m-%dT%H:%M:%S+08:00', 'now')")` 与 DDL 对齐
- relationship 定义完整外键关系与级联删除（`cascade="all, delete-orphan"`）
- User ORM 命名为 `user_orm.py`，与现有 `user.py`（Mock 内存用户）并存

class ErrorCode:
    BAD_CREDENTIALS = (40101, "用户名或密码错误", 401)

    REFRESH_TOKEN_INVALID = (40103, "refresh_token 无效或已过期", 401)

### 5.2 数据库初始化（database.py）

```python
DB_DIR = Path(__file__).resolve().parent.parent.parent.parent / "database"
SCHEMA_SQL_PATH = DB_DIR / "schema.sql"
INIT_DATA_SQL_PATH = DB_DIR / "init_data.sql"

def init_db():
    with engine.connect() as conn:
        raw_conn = conn.connection
        if SCHEMA_SQL_PATH.is_file():
            schema_sql = SCHEMA_SQL_PATH.read_text(encoding="utf-8")
            raw_conn.executescript(schema_sql)
        if INIT_DATA_SQL_PATH.is_file():
            result = conn.execute(text("SELECT COUNT(*) FROM roles"))
            if result.scalar() == 0:
                init_sql = INIT_DATA_SQL_PATH.read_text(encoding="utf-8")
                raw_conn.executescript(init_sql)
        conn.commit()
```

### 5.3 应用启动集成（main.py）

```python
@asynccontextmanager
async def lifespan(app: FastAPI):
    init_db()
    yield

def create_app() -> FastAPI:
    app = FastAPI(title=settings.APP_NAME, version=settings.APP_VERSION,
                  debug=settings.DEBUG, lifespan=lifespan)
    app.add_middleware(CORSMiddleware, allow_origins=["*"],
                       allow_credentials=True, allow_methods=["*"], allow_headers=["*"])
    register_exception_handlers(app)
    app.include_router(api_router, prefix=settings.API_V1_PREFIX)
    return app
```
