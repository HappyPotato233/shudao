# 前端风格指南 — 品牌卡片（渐变头部 + 数据统计）

> 版本：v1.0 ｜ 适用：蜀道安全助手前端（Vue 3 + TypeScript + Element Plus）
> 风格基调：渐变品牌头部、白底数据区、粗黑描边硬阴影、响应式适配

---

## 一、风格概述

本风格源自社交平台品牌卡片范式，核心特征是**"渐变头部 + 数据统计区"的双层结构**，并叠加**"hover 圆形角标扩散铺满 + 文字反白"**的强反馈交互：

- 头部使用**蓝紫渐变**（`#5F72FF → #9A4EFF`）承载品牌标识、状态徽章与名称
- 底部白底数据区用分隔线划分统计项，信息密度高、可读性强
- 融合粗黑描边 + 硬阴影（Neo-Brutalism 元素），在柔和渐变中保留硬朗轮廓
- **核心交互**：hover 时右上角圆形角标从 50px 扩散至 900px 铺满整卡，图标/标题/数据文字反白，形成强烈的"聚焦/选中"反馈
- hover 位移 + 阴影加深，反馈直接

适用场景：品牌/账号信息卡、数据概览卡、连接状态卡、指标展示卡。

---

## 二、设计原则

| 原则 | 说明 |
|---|---|
| 双层结构 | 头部（品牌/状态）+ 数据区（指标）分离，信息层级清晰 |
| 渐变头部 | 品牌区用高饱和渐变（蓝紫系），营造品牌感与视觉焦点 |
| 白底数据区 | 数据用白底承载，与彩色头部形成强对比，聚焦数字 |
| 硬朗轮廓 | 4px 粗黑描边 + 8px 硬阴影，与渐变形成"柔中带刚" |
| 扩散反馈 | hover 时右上角圆形角标扩散铺满整卡、文字反白，反馈强烈且直观 |
| 响应式 | 小屏（≤480px）自动降级描边/阴影/字号 |

## 六、组件规范

### 1. 品牌卡片（Brand Card）

- 结构：头部（`.card-header`）+ 数据区（`.card-stats`）
- 头部：渐变背景 + 图标 + 状态徽章 + 品牌名 + handle
- 数据区：白底，统计项横向均分，`border-right` 分隔

### 2. 状态徽章（Status Badge）

- 半透明白底胶囊（`rgba(255,255,255,0.25)`），白字
- 用于连接状态、在线状态等轻量标识

### 3. 统计项（Stat）

- 数字 + 标签纵向排列，居中
- 数字用深色加粗，标签用灰色小字
- 非末项右侧 1px 分隔线（`#E1E8ED`）

### 4. 品牌图标（Brand Icon）

- 白色 SVG，28×28px，置于头部左上角

### 5. 扩散角标（Expand Badge）

- 绝对定位右上角，圆形，承载序号/编号
- 扩散动画由 `::after` 伪元素实现：初始 50px 圆 → hover 时扩至 900px 铺满整卡
- 扩散后图标/标题/数据文字反白（`#F5F5F5`），形成"聚焦/选中"反馈

---

## 七、交互与动效规范

| 状态 | 动效 | 时长 |
|---|---|---|
| 卡片 hover | `translate(-2px, -2px)` + 阴影加深至 `10px 10px 0` | 0.2s ease |
| 小屏 hover | 阴影加深至 `8px 8px 0` | 0.2s ease |
| **角标扩散（核心）** | `::after` 从 50px 扩至 900px 铺满整卡 | 0.5s |
| **文字反白（核心）** | 图标/标题/数据文字变 `#F5F5F5` | 0.5s |

> 动效统一 `transition: all 0.2s ease`，轻快不拖沓；扩散动画 0.5s 略慢于位移，形成层次。

---

## 八、响应式规范

| 断点 | 调整项 |
|---|---|
| `max-width: 480px` | 宽度 320→300px；描边 4→3px；阴影 8→6px；品牌名 28→24px；数字 20→18px；标签 13→12px |

> 原则：小屏降级描边/阴影/字号，保持结构不变，不重排布局。

## 十、使用注意事项

1. **渐变克制**：渐变仅用于品牌头部，数据区保持白底，避免全卡渐变导致数字难读。
2. **硬阴影与渐变共存**：粗黑描边 + 硬阴影是风格记忆点，勿替换为柔和阴影。
3. **扩散动画性能**：900px 圆形扩散在低端设备可能卡顿，可改用 `transform: scale()` 提升性能。
4. **反白对比度**：扩散后文字反白（`#F5F5F5`）需与填充色保证对比度 ≥ 4.5:1；红绿色盲用户需辅以图标/文字标识。
5. **可访问性**：渐变头部白字需保证对比度；`opacity: 0.9` 的 handle 在浅色渐变上需检查可读性。
6. **响应式必做**：小屏降级描边/阴影/字号，避免卡片溢出；扩散角标尺寸按容器比例缩放。
7. **与 Element Plus 共存**：覆盖默认样式时使用 `:deep()` 或 CSS 变量。
