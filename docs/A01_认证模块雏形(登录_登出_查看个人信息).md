## 2. 实现的接口

基础路径：`http://{host}:{port}/api/v1`，认证方式：`Authorization: Bearer <token>`

| 方法 | 路径          | 功能           | 鉴权 | 备注                                   |
| ---- | ------------- | -------------- | ---- | -------------------------------------- |
| POST | `/auth/login`  | 登录           | 否   | 返回 access_token / refresh_token / user |
| POST | `/auth/logout` | 退出登录       | 是   | 吊销当前 access_token（jti 黑名单）     |
| GET  | `/auth/me`     | 查看个人信息   | 是   | 返回当前登录用户信息                    |

### 2.1 登录请求/响应（对齐 API.md 2.1）

请求体：
```json
{ "username": "zhangsan", "password": "Abc@123456" }
```

成功响应：
```json
{
  "code": 0,
  "message": "success",
  "data": {
    "access_token": "eyJhbGciOi...",
    "refresh_token": "eyJhbGciOi...",
    "expires_in": 7200,
    "user": {
      "id": "U002", "username": "zhangsan", "name": "张三",
      "role": "SafetyOfficer", "department": "安全生产部", "project": "成绵高速扩容项目"
    }
  },
  "timestamp": 1692000000
}
```

### 2.2 业务错误码（对齐 API.md 附录）

| 错误码 | 说明                 | 触发场景                       |
| ------ | -------------------- | ------------------------------ |
| 40001  | 参数校验失败         | 缺少必填字段（username/password） |
| 40101  | 用户名或密码错误     | 用户不存在或密码错误            |
| 40102  | 账户已被禁用         | 登录禁用账户（wangwu）          |
| 40104  | 未认证或 Token 过期  | 未携带 Authorization 头         |
| 40105  | Token 无效           | token 解析失败 / 已被登出吊销   |

## 4. 关键设计要点

1. **统一响应结构**：`{code, message, data, timestamp}`，全局异常处理器把 `BizError`、`RequestValidationError`、未捕获异常统一映射为该结构。
2. **JWT 双 Token**：access_token（2 小时，PRD 5.2.1）+ refresh_token（7 天）。本次未实现 `/auth/refresh` 接口，但登录响应已返回 refresh_token 以保持前向兼容。
3. **BCrypt 加盐**：密码哈希使用 passlib CryptContext，Mock 用户密码在模块加载时统一哈希。
4. **登出真生效**：access_token 携带 `jti`，登出时加入进程内黑名单集合，后续请求命中黑名单返回 40105。雏形阶段重启即清空，可接受。
5. **分层高内聚**：core/schemas/models/services/api 各司其职。接入数据库时仅需将 `models/user.py` 的 `find_user_by_username/id` 换成 SQLAlchemy 查询。
6. **安全细节**：用户不存在与密码错误统一返回 40101，避免暴露用户是否存在。

## 7. 运行方式

```powershell
# 启动开发服务
conda run -n shixi python -m uvicorn app.main:app --reload --port 8000

# 运行测试
$env:PYTEST_DISABLE_PLUGIN_AUTOLOAD="1"
$env:PYTHONDONTWRITEBYTECODE="1"
conda run -n shixi python -m pytest tests/ -p no:cacheprovider
```

> **环境说明**：使用 conda 环境 `shixi`（Python 3.12.7）。测试需设 `PYTEST_DISABLE_PLUGIN_AUTOLOAD=1`，因 shixi 环境的 `langsmith` 注册了 pytest 插件，其写 `.pyc` 会触发沙箱限制。passlib 对 bcrypt 4.x 的版本检测告警无害，哈希功能正常。
